# ХвостКом — груминг и уход за питомцами

**Степанов Михаил Александрович · ЭФБО-05-25**

Контрольная работа №2: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке». Практические занятия №9–11.

Учебный многостраничный сайт: каталог из шести услуг для собак и кошек, сравнение стоимости и длительности, памятка владельцу и демонстрационная запись. Версия 2.0 от 11 ноября 2026 года сохраняет собственную зелёно-кремовую палитру салона и добавляет полезные функции по выбранному пользователем [образцу Proks](https://sysoev973.github.io/Proks_site/): поиск, памятку, интерактивное сравнение, расчёт визитов, историю изменений и две языковые версии. HTML, CSS и JavaScript написаны для «ХвостКом» заново; код и материалы образца не включены. [Соответствие разделов образцу](docs/REFERENCE-MAPPING.md).

## Открыть на Mac

1. Распакуйте архив и откройте папку `kr2-bootstrap-shop` в **VS Code → File → Open Folder…** или **WebStorm → Open**.
2. Откройте `index.html` двойным щелчком в Finder или через команду редактора Open in Browser. Сборка и установка пакетов не нужны.
3. Для автоматического обновления в VS Code можно использовать Live Server. Для английской версии откройте `en/index.html` или нажмите EN на сайте.

[Пошаговое объяснение, проверка и Git](docs/START-HERE.md).

## Bootstrap и структура

Используется **Bootstrap 5.3.8 локально**: `vendor/bootstrap/css/bootstrap.min.css` и `vendor/bootstrap/js/bootstrap.bundle.min.js`. Собственный `css/custom.css` подключён после Bootstrap; Bundle включает Popper. Исторический этап практики №9 использует CDN. [Официальная документация Bootstrap](https://getbootstrap.com/docs/5.3/getting-started/download/), лицензия MIT сохранена в `vendor/bootstrap/LICENSE`.

## Доработки сверх базового примера

- Шесть услуг из единого набора данных: стрижка, купание, гигиена, когти, экспресс-линька и первое знакомство. Фильтр оставляет четыре услуги для кошек и шесть для собак.
- Переход `каталог → услуга → запись` сохраняет выбор через `?service=...`. Переключение RU/EN сохраняет параметры адреса и якорь.
- Поиск по страницам, памятке и услугам работает без сервера; поддерживает стрелки, Enter, Escape и сообщение о пустом результате.
- Калькулятор рассчитывает предварительную стоимость и суммарную длительность 1–12 одинаковых визитов. Для кошек исключает неподходящие услуги.
- Интерактивное прохождение этапов визита: старт, пауза, следующий этап и сброс.
- Сравнение всех услуг: график с переключаемыми рядами цены и времени, подсказками мышью и клавиатурой; ниже — точные данные таблицы. Шкалы рублей и минут нормированы отдельно.
- Памятка владельцу с оглавлением, копированием текста и скачиванием `.txt`; при недоступном буфере текст выделяется для ручного копирования.
- Форма проверяет имя, e-mail, 10 цифр телефона, кличку, совместимость услуги с питомцем, согласие, дату и время. Начала — раз в полчаса в ближайшие 90 дней, окончание ухода — не позднее 19:00.
- Единое оформление в зелёно-кремовой палитре, мобильное меню до 1200 px, ссылка пропуска навигации, видимый фокус и кнопка «Наверх».

[Таблица требований №9–11](docs/REQUIREMENTS.md). Оценка зависит от выполнения критериев и объяснения кода студентом.

## Проверка и ограничения

[Ручной список проверки](docs/CHECKLIST.md) и [отчёт о фактически выполненных проверках](docs/VERIFICATION.md) разделяют старую версию и новую. Проверки и скриншоты версии 1 не подтверждают работу версии 2.

Это frontend-проект: форма показывает итог и **не отправляет заявку, не бронирует время и не принимает оплату**. Введённые данные не сохраняются в localStorage, cookie или на сервере; пользовательский ввод выводится через `textContent`. Калькулятор планирует расходы, а форма оформляет один демонстрационный визит. Цены и расписание учебные; SVG в галерее — иллюстрации, не фотографии реальных работ.

`images/salon-dog.png` — сгенерированный декоративный портрет пуделя для первого экрана. Он создан для этого проекта, согласован с зелёно-кремовой палитрой и не представлен как фотография работы действующего салона.
