## Подключение Bootstrap

Итоговая версия использует **Bootstrap 5.3.8 локально**: `vendor/bootstrap/css/bootstrap.min.css` и `vendor/bootstrap/js/bootstrap.bundle.min.js`. CSS салона подключён после Bootstrap. Bundle включает Popper и обеспечивает работу меню, модального окна и accordion. Весь сайт работает без интернета; исходный коммит практики №9 показывает CDN-подключение.

Официальные исходники: https://getbootstrap.com/docs/5.3/getting-started/download/ . Лицензия MIT сохранена в `vendor/bootstrap/LICENSE`. Карты исходников `.map` необязательны и не включены.

## Запуск на macOS

1. Откройте **именно папку `kr2-bootstrap-shop`** в VS Code: File → Open Folder… (`⌘O`).
2. Откройте `index.html` в Finder двойным щелчком. Для этого варианта сервер не нужен.
3. Для автоматического обновления установите расширение Live Server автора Ritwick Dey из Marketplace VS Code и выберите Open with Live Server в контекстном меню `index.html`.
4. Не открывайте отдельные HTML через просмотр исходного текста: нужен браузер.

Подробная последовательность действий, пояснения к коду, Git и Pull Request: [docs/START-HERE.md](docs/START-HERE.md).

## Самостоятельные доработки по №11

- Локальный Bootstrap: отключите интернет и проверьте меню, модальное окно и accordion.
- Две дополнительные страницы: «До и после» и «О салоне».
- Фильтрация каталога: для кошки скрывается стрижка, остаются две услуги; количество сообщается через `aria-live`.
- Сценарий `каталог → выбранная услуга → запись`: параметр `?service=bath` сохраняет выбор при переходах. Неизвестные параметры не ломают страницу.
- Форма проверяет обязательные поля, e-mail, 10 цифр телефона, непустые имена, совместимость услуги с питомцем, согласие, дату и время.
- Предлагаются только будущие получасовые начала в ближайшие 90 дней. С учётом длительности процедура должна закончиться до 19:00. Это демонстрационное расписание, без учёта реальной занятости.
- В форме видны предварительная цена и длительность, после проверки — текст заявки. Сброс очищает ошибки и результат.
- Единое оформление, адаптивные карточки, прокручиваемая таблица, подписи полей, видимый фокус, ссылка пропуска навигации.

Это осмысленные расширения пользовательского сценария, а не только замена текста и цветов. Оценка зависит от демонстрации и понимания кода студентом.

## Проверка и ограничения

См. [docs/CHECKLIST.md](docs/CHECKLIST.md). Не считайте пункты ручной проверки выполненными, пока не проверили их сами.

Это frontend КР №2: **нет backend, реальной отправки заявок, платежей и бронирования**. Данные не сохраняются в localStorage, cookie или на сервере. Не используйте реальные персональные данные в демонстрации. Отображение введённого текста выполняется через `textContent`.

В галерее — иллюстрации, а не реальные фотографии работ. Для замены используйте согласованные фото одного питомца; обновите `src`, `alt` и подписи в `gallery.html`. Цены, режим работы и описание салона вымышлены для учебного примера. Фотографии и контакты действующего салона не предоставлены.
