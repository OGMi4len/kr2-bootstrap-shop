# Какие функции образца адаптированы под «ХвостКом»

Пользователь выбрал [https://sysoev973.github.io/Proks_site/](https://sysoev973.github.io/Proks_site/) как функциональный образец. Изучены главная, документация, изменения, бенчмарки и доступные клиентские сценарии. Для «ХвостКом» выбраны полезные взаимодействия и адаптированы под груминг.

Внешний вид салона самостоятельный: сохранены зелёно-кремовая палитра и собственная подача. Тёмная техническая стилистика Proks и его крупный wordmark не являются целью копирования. HTML, CSS и JavaScript новой версии написаны для «ХвостКом» заново. Исходники, тексты, изображения, логотип, данные измерений и программные алгоритмы Proks в проект не перенесены. Источник функционального примера указан в README.

|---|---|---|

## Границы соответствия

Эта таблица описывает выбранные функциональные соответствия; полного тождества двух сайтов не заявлено. Технический сайт Proks описывает Go-прокси: кэш, TinyLFU, LRU, предзагрузку, RabbitMQ и измерения производительности. Эти серверные функции не относятся к груминг-салону. В нашем проекте полезны выбор ухода, расчёт цены, сравнение услуг и подготовка к визиту.

График «ХвостКом» показывает демонстрационные цены и длительность, а не производительность программы или качество груминга. Каждый ряд нормирован по собственной шкале; точные значения подписаны и приведены в таблице. Цена из калькулятора — сумма одинаковых визитов без скидок, форма записи проверяет один визит.

Раздел истории — статический снимок известных этапов с настоящими ссылками GitHub. Автоматическая сборка сайта из внешних релизов и серверная синхронизация не реализованы. Поиск хранит индекс локально, чтобы HTML открывался на Mac без сборки и сервера.

Каталог, отдельная услуга, форма, modal и accordion сохранены как требования №9–11. Технические файлы обязательных страниц не переименованы. Заявки не отправляются и время не бронируется.

Реальные действия в браузере и внешний вид новой версии требуют проверки по [CHECKLIST.md](CHECKLIST.md). Результаты прошлой версии не считаются проверкой новой. См. [VERIFICATION.md](VERIFICATION.md).
