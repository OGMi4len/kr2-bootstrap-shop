# Мастер отзывов «ХвостКом»

## Проверить на Mac

1. Откройте папку проекта в VS Code. Выберите **Terminal → New Terminal**.
2. Запустите `python3 server.py`. Пакеты устанавливать не нужно. Откройте `http://127.0.0.1:8080/reviews.html` в браузере. Если порт занят, выполните `python3 server.py serve --port 8081` и откройте адрес с портом 8081.
3. Нажмите «Оставить отзыв», выберите звёзды, введите имя и текст, проверьте карточку и отправьте. Пока отзыв на проверке, его не будет в общей ленте.
4. Откройте **второй** терминал VS Code, оставив сайт запущенным. Выполните `python3 server.py list`. Найдите номер (`id`) своего отзыва. Выполните `python3 server.py approve 1`, заменив `1` на этот номер.
5. Обновите страницу. Отзыв появится в ленте, в том числе в приватном окне браузера. Команда `python3 server.py reject 1` скроет запись, `python3 server.py list --status all` покажет и ранее проверенные отзывы. Чтобы остановить локальный сайт, нажмите `Ctrl+C` в первом терминале.

Данные хранятся в `var/reviews.sqlite3` и сохраняются при перезапуске. Этот файл не попадает в Git. В форме не спрашиваются телефон и почта: публикуются имя, оценка, услуга (если выбрана), текст и дата. Модерация доступна только из терминала на машине с базой.

## Публичный запуск

GitHub Pages и Live Server обслуживают статическую часть. Без сервиса отзывов страница помечена как предпросмотр; локальные отзывы других посетителей не видны и в базу не переносятся.

Для общей публичной ленты запустите сайт на хостинге с поддержкой Python и постоянным диском. `server:application` — точка входа для WSGI-сервера. Сайт и `/api/reviews` должны работать с одного адреса по HTTPS, из корня сайта. Задайте `HVOSTKOM_REVIEWS_DB` абсолютным путём к файлу на постоянном диске; тот же путь используйте для команд модерации и резервного копирования. Локальный запуск через `python3 server.py` предназначен для проверки. Перед открытой публикацией настройте на хостинге ограничение частоты запросов к `/api/reviews`, чтобы защитить очередь модерации от спама.
