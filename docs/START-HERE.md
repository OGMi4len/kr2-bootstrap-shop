# Как открыть и проверить «ХвостКом» на Mac

Степанов Михаил Александрович, ЭФБО-05-25. Текущая редакция версии 2.0, практические занятия №9–11, КР №2. Файлы уже готовы; перепечатывать код из чата не нужно.

## 1. Распакуйте и откройте папку

В Finder дважды нажмите на ZIP. Найдите внутри папку `kr2-bootstrap-shop`: в ней лежат `index.html`, `catalog.html`, `order.html` и папки `css`, `js`, `en`, `vendor`.

В **VS Code** выберите File → Open Folder… и эту папку. В **WebStorm** выберите Open на стартовом экране или File → Open. Открывать нужно всю папку, чтобы редактор видел связанные файлы.

Для запуска зависимостей нет: команды `npm install` и сборка не требуются.

## 2. Откройте сайт

Самый простой способ: дважды нажмите `index.html` в Finder. В WebStorm можно открыть файл в редакторе и выбрать Open in Browser в его контекстном меню. В VS Code для автоматического обновления: Extensions (`⇧⌘X`) → Live Server автора Ritwick Dey → Install → правый щелчок на `index.html` → Open with Live Server.

Сохраняйте правки через `⌘S`. Если открыли файл без Live Server, обновляйте браузер через `⌘R`. Локальный адрес браузера ещё не означает публикацию сайта в интернете.

Ожидаемый результат: главная «ХвостКом» в зелёно-кремовой палитре со скруглённой стеклянной шапкой и мягкими бликами, с шестью услугами, калькулятором и этапами визита. В шапке должны быть пять разделов: «Главная», «Услуги», «О салоне», «Контакты», «До и после». В списке разделов подвала — четыре: «Главная», «Услуги», «О салоне», «До и после». Контактные сведения остаются отдельной колонкой. В шапке рядом с названием — изображение лапки. «Перед визитом» открывается кнопкой «Первый визит?» на первом экране или через поиск, а не пунктом меню. Кнопка EN открывает английскую версию. Если видите прежний каталог только с тремя услугами, открыта старая папка или старая вкладка.

## 3. Пройдите основной сценарий записи

1. На первом экране нажмите новую кнопку «Записаться»: форма откроется на главной. Закройте её. Прежние «Подобрать уход» и «Первый визит?» также должны остаться. Затем откройте «Услуги». Для кошки остаются четыре карточки, для собаки доступны все шесть.
2. Нажмите «Выбрать» у купания: на этой же странице сразу откроется полная форма записи, купание уже выбрано. Промежуточного окна подтверждения услуги нет.
3. Закройте окно крестиком или Escape, затем откройте его снова. Фокус должен попадать в имя; окно не должно дублироваться.
4. Заполните форму вымышленными данными для проверки. Телефон вводится десятью цифрами без `+7`: префикс уже стоит слева.
5. Выберите дату в ближайшие 90 дней с понедельника по субботу и предложенное время. График — 10:00–18:00, воскресенье закрыто; процедура должна закончиться до 18:00.
6. Нажмите «Продолжить». При корректных данных появятся «Детали визита готовы» и кнопки звонка/письма для согласования времени с администратором. Это не сообщение об отправленной заявке или подтверждённом бронировании.
7. Измените поле — старый итог скроется. «Очистить» сбрасывает значения, ошибки и итог. Повторное открытие окна снимает прежние сообщения проверки.

«Подробнее» по-прежнему открывает отдельную страницу услуги. Кнопка записи на ней открывает ту же форму с нужной услугой. Неизвестный адрес `product.html?service=unknown` показывает базовую стрижку без ошибки.

Для прямого открытия можно использовать `index.html?booking=1&service=bath#bookingModal`. Старый `order.html?service=bath` перенаправляет на главное окно записи с сохранением параметров; в EN действует `en/order.html`. Без JavaScript на совместимом переходе доступен телефон салона. Отдельной полноценной страницы формы больше нет.

## 4. Проверьте новые разделы

- В поиске введите «купание» или «перед визитом». Выберите результат мышью либо стрелками и Enter; Escape закрывает список. Для случайного набора букв должно появиться сообщение, что ничего не найдено.
- На главной выберите кошку в калькуляторе. Доступны четыре подходящие услуги. Например, три купания дают предварительно 4800 ₽ и 180 минут. Нулевое, дробное или большее 12 число визитов не должно открывать запись. При корректном расчёте кнопка открывает окно с услугой и питомцем из калькулятора.
- В блоке «Как проходит визит» попробуйте «Старт», «Паузу», «Следующий этап», «Сброс». Это демонстрация процесса.
- В разделе «Перед визитом» прочитайте короткие советы, скопируйте список вещей и скачайте текст. Если браузер не даёт доступ к буферу, текст выделится: нажмите `⌘C`.
- Переключите EN на странице услуги с параметром в адресе. Должны сохраниться услуга и соответствующая страница. Все семь основных страниц имеют английские версии; оба старых order-адреса работают как переходы к записи.
- Откройте отдельно «О салоне», «До и после» и «Контакты». На странице контактов проверьте адрес, телефон, почту, встроенную Яндекс Карту и график. В подвале контактные сведения идут в порядке: адрес/карта → телефон → график → e-mail, с небольшими SVG-символами. В «До и после» должно быть шесть настоящих фото-примеров со ссылками на авторов, источники и лицензии: три пары «до/после» и три кадра ухода/результата. Отдельные кадры не подписаны как парное сравнение, все фото не выдаются за работы нашего салона. Ссылка «Наверх» возвращает к началу.
- Пункта записи среди пяти разделов меню нет: откройте окно через кнопку на главной, у услуги, из калькулятора или результата поиска «запись». Кнопка записи может быть отдельно от списка разделов в подвале. Отдельные публичные страницы сравнения и технических изменений удалены.

Полный список: [CHECKLIST.md](CHECKLIST.md). Отмечайте только собственноручно проверенные пункты.

## 5. Проверьте экран телефона и клавиатуру

В инструментах разработчика браузера изменяйте ширину на 375, 768, 1024 и 1440 CSS px. На маленьком экране сайт не должен прокручиваться целиком вбок. Таблицы могут прокручиваться внутри своего блока.

Карточки идут в одну колонку на 375 px, две на 768 px и три на 1024/1440 px. Меню свёрнуто до 1200 px; начиная с 1200 px показывается полная навигация. Поэтому на 1024 px кнопка меню ожидаема.

Пройдите сайт клавишей Tab: должна появляться видимая рамка фокуса, первой доступна ссылка «Перейти к содержимому». Проверьте форму, поиск, меню и кнопки без мыши. Затем проверьте браузер с отключённым интернетом: Bootstrap и данные находятся в проекте. Фото галереи находятся локально и должны открываться без сети. Встроенная Яндекс Карта загружается из интернета, поэтому при отключённой сети её отсутствие ожидаемо.

## 6. Разберитесь в коде

| Файл | Что объяснить на защите |
|---|---|
| `index.html` | Секции главной, Bootstrap-сетка и быстрые переходы |
| `catalog.html` | Карточки, фильтр, метки и прямое открытие формы записи |
| `product.html` | Таблица, FAQ, данные услуги из адреса |
| `#bookingModal` на основных HTML | Полная форма с `label`, `name`, `required` и Bootstrap-классами |
| `order.html`, `en/order.html`, `js/booking-redirect.js` | Совместимость старых адресов и передача параметров на главную |
| `about.html` и `contacts.html` | Отдельные страницы о салоне и для связи |
| `guide.html` | Короткая практическая подготовка и список вещей |
| `js/services.js` | Единые данные шести услуг, русские и английские тексты |
| `js/app.js` | Фильтр, URL-параметры, modal и проверка заявки |
| `js/enhancements.js` | Поиск, открытие записи из калькулятора, интерактивные этапы и список подготовки |
| `css/custom.css` | Базовое оформление поверх Bootstrap |
| `css/liquid-glass.css` | Отдельный слой стеклянной темы, загруженный последним |

`container` ограничивает ширину, `row` содержит колонки, `col-*` и `row-cols-*` меняют их количество. `g-*` задаёт промежутки. `card`, `btn`, `badge` и `alert` оформляют интерфейс; JS Bundle управляет `navbar`, `modal` и `accordion`.

`preventDefault()` останавливает обычную отправку формы, `checkValidity()` проверяет ограничения, `was-validated` показывает Bootstrap-сообщения. `textContent` выводит введённое как текст. Совместимость услуги берётся из массива `pets`. Воскресенье не даёт времени для записи, а в понедельник–субботу процедура должна закончиться до 18:00. Начала предлагаются с 10:00 раз в полчаса.

## 7. Проверьте Git перед сохранением

В VS Code откройте Terminal → New Terminal; в WebStorm — вкладку Terminal. Вводите команды по одной, нажимая Enter:

```sh
pwd
git status
git branch --show-current
git remote -v
```

`pwd` показывает папку, `status` — изменения, `branch` — текущую ветку, `remote` — связанный GitHub. Не вводите перед командами символ `$`.

Если получили `not a git repository`, папка из ZIP содержит только исходники. Не создавайте Git в общей папке Documents. Для получения истории существующего проекта можно отдельно клонировать его в новую папку:

```sh
git clone https://github.com/OGMi4len/kr2-bootstrap-shop.git hvostkom-from-github
```

Клон по умолчанию открывает основную ветку `main`. Ветка `feature/reference-redesign` сохраняет историю разработки новой версии. Архивы и Git bundle отражают состояние на дату их создания; актуальность сверяйте с коммитами репозитория. Новые самостоятельные изменения выполняйте в отдельной ветке и передавайте через Pull Request.

Для исходной рабочей папки новая ветка уже подготовлена: `feature/reference-redesign`. Исторические ветки №9 и №10 показывают этапы разработки; PR №1–4 уже объединены, создавать их повторно не нужно.

## 8. Сохраните новую версию и создайте PR

Выполняйте этот шаг после проверки сайта и просмотра своих изменений. Если коммит уже подготовлен, повторный `commit` без новых изменений не нужен.

```sh
git diff --stat
git diff --check
git add .
git commit -m "feat: redesign HvostKom and extend care planning"
git push -u origin feature/reference-redesign
```

`add` подготавливает изменения, `commit` сохраняет их локально, `push` загружает ветку в GitHub. В GitHub Desktop те же действия называются Commit и Publish branch / Push origin. Убедитесь, что выбран ваш аккаунт и репозиторий `OGMi4len/kr2-bootstrap-shop`.

На GitHub: Pull requests → New pull request → **base: main**, **compare: feature/reference-redesign** → Create pull request. В описании перечислите окончательные изменения: полную форму в одном модальном окне каждой основной страницы, выбор услуги/питомца, совместимые order-переходы, согласование записи по телефону/почте, пять разделов шапки и четыре раздела подвала и предоставленные контакты/график. Укажите выполненные проверки и ограничения формы. Откройте Files changed и проверьте состав файлов. После проверки объедините PR через Merge pull request → Confirm merge.

Когда PR объединён, а незакоммиченных правок нет, обновите локальную основную ветку:

```sh
git switch main
git pull --ff-only
git status
```

Ожидается `working tree clean`. Если Git сообщает об ошибке, не выполняйте `reset --hard`, `clean` или force push: сначала разберите сообщение.

В СДО сдаётся ссылка [на репозиторий](https://github.com/OGMi4len/kr2-bootstrap-shop). GitHub Pages необязателен. Статус публикации новой версии проверяйте по фактическому PR, а не по наличию архива.

## 10. Проверьте стеклянную тему

Стили подключены последовательно: Bootstrap, `css/custom.css`, затем `css/liquid-glass.css`. Последний файл меняет внешний вид, сохраняя зелёно-кремовые цвета и работу Bootstrap. Размытие относится преимущественно к навигации и элементам управления; текстовые блоки имеют более плотный фон. Это оформление средствами CSS, вдохновлённое Apple Materials.

Проверьте на своём Mac читаемость шапки, кнопок, подвала, полей и формы поверх разных участков страницы. В настройках уменьшения прозрачности/движения и повышения контраста эффект должен становиться проще. Если браузер не поддерживает размытие, остаётся фоновая заливка. В ходе автоматической проверки реальные цвета и размытие на экране не измерялись.
