# Проверка версии 2.0 перед демонстрацией

Отмечайте пункт только после собственной проверки этой версии. Фактически выполненные проверки перечислены отдельно в [VERIFICATION.md](VERIFICATION.md).

## Историческая личная проверка версии 1

- [x] В исходной версии проверено в Safari: карточки в одну колонку на 375 px, две на 768 px, три на 1024 и 1440 px. Отметка сохранена из [PR №4](https://github.com/OGMi4len/kr2-bootstrap-shop/pull/4); она не подтверждает новую версию 2.0.

## Страницы, языки и адаптивность

- [ ] Откройте девять RU-страниц: index, catalog, product, order, gallery, contacts, guide, comparison, changelog.
- [ ] Откройте те же девять страниц в `en/`: переведены навигация, основные тексты, услуги и сообщения взаимодействий.
- [ ] На 375, 768, 1024 и 1440 CSS px нет горизонтальной прокрутки всего документа; таблицы и график прокручиваются внутри своего блока.
- [ ] Карточки: одна колонка на 375 px, две на 768 px, три на 1024/1440 px.
- [ ] До 1200 px меню открывается и закрывается кнопкой; с 1200 px полная навигация помещается вместе с поиском и языком.
- [ ] Текущий раздел выделен; для product активны «Услуги».
- [ ] Кнопка языка ведёт на соответствующую страницу и сохраняет `?service=bath` и якорь раздела.
- [ ] Якоря и «Наверх» не прячут заголовок под закреплённой шапкой.

## Каталог, услуга и окно выбора

- [ ] Все питомцы: шесть услуг; собаки: шесть; кошки: четыре. Для кошек скрыты стрижка и первое знакомство.
- [ ] Счётчик соответствует числу видимых карточек.
- [ ] У всех шести услуг окно «Выбрать» показывает правильное название, цену и длительность.
- [ ] Окно закрывается крестиком, Escape и кнопкой «Назад»; повторно открывается.
- [ ] Переход из окна и страницы услуги к записи сохраняет выбранную услугу.
- [ ] «Подробнее» открывает правильные название, изображение, описание, таблицу и ссылку записи для всех услуг.
- [ ] Accordion раскрывает и закрывает ответы.
- [ ] Неизвестный `product.html?service=unknown` показывает базовую услугу без ошибки.

## Поиск и памятка

- [ ] Поиск «купание» или «bath» на соответствующем языке находит услугу; переход открывает нужную страницу.
- [ ] Несколько слов ищутся вместе, пробелы по краям не мешают, пустой запрос закрывает список.
- [ ] Случайный запрос показывает «Ничего не найдено»; стрелки, Enter и Escape работают.
- [ ] Щелчок вне поиска и переход фокуса закрывают результаты.
- [ ] Оглавление памятки открывает соответствующий раздел.
- [ ] Копирование переносит текст памятки в буфер; при недоступном буфере текст выделяется для `⌘C`.
- [ ] Скачивание создаёт читаемый `.txt` на нужном языке.

## Калькулятор и интерактивные этапы

- [ ] Одно купание: от 1600 ₽ и 60 мин; три: от 4800 ₽ и 180 мин.
- [ ] Для кошки калькулятор исключает стрижку и первое знакомство; переключение питомца оставляет подходящий выбор.
- [ ] Пустое, нулевое, отрицательное, дробное или большее 12 число визитов отклоняется; переход записи недоступен.
- [ ] «Сбросить» возвращает калькулятор к исходному состоянию.
- [ ] Ссылка калькулятора передаёт услугу; форма создаёт один визит, а не несколько бронирований.
- [ ] «Старт» последовательно показывает четыре этапа; «Пауза» останавливает; «Следующий этап» работает вручную; «Сброс» очищает состояние; «Повторить» запускает заново.

## Сравнение

- [ ] Таблица содержит шесть услуг с теми же ценами и длительностью, что каталог.
- [ ] Кнопки легенды независимо скрывают и возвращают ряды цены и времени.
- [ ] Подсказка появляется по наведению и фокусу Tab, Escape её закрывает.
- [ ] Подпись объясняет отдельные шкалы: 2400 ₽ для максимума цены и 90 минут для максимума времени.
- [ ] Ссылки таблицы открывают правильную услугу и запись.

## Форма

- [ ] Пустая форма показывает ошибки и переводит фокус на первое ошибочное поле.
- [ ] Неверный e-mail, телефон не из десяти цифр, имя/кличка из пробелов отклоняются.
- [ ] Кошка + стрижка или первое знакомство отклоняется; кошка + купание, гигиена, когти или экспресс-линька проходит.
- [ ] Вчера и дата дальше 90 дней отклоняются; сегодня предлагаются только будущие начала.
- [ ] Начала идут раз в полчаса, окончание процедуры не позже 19:00. Для стрижки последнее начало 17:30, купания 18:00, экспресс-линьки 17:30, гигиены/первого знакомства/когтей 18:30.
- [ ] Без согласия заявка не проходит.
- [ ] Корректные вымышленные данные показывают итог и пояснение об отсутствии отправки.
- [ ] Изменение данных скрывает старый итог; очистка убирает значения, ошибки и результат.
