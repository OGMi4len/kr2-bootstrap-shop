# Проверка перед демонстрацией преподавателю

Эти квадраты оставлены для вашей личной проверки. Фактически выполненные автоматизированные и браузерные проверки перечислены отдельно в VERIFICATION.md.

## Страницы и адаптивность

- [ ] Откройте index, catalog, product, order, gallery, contacts.
- [ ] На каждой странице проверьте 375, 768, 1024, 1440 px: нет горизонтального прокручивания документа, изображения не растягивают экран.
- [ ] На 375 и 768 px мобильное меню открывается и закрывается; с 992 px видна полная навигация.
- [x] Карточки услуг: 1 колонка на 375, 2 на 768, 3 на 1024 и 1440 px.
- [ ] Текущий раздел выделен, на странице отдельной услуги выделены «Услуги».
- [ ] Таблица остаётся внутри table-responsive, форма и окно помещаются на мобильном экране.
  
## Компоненты и сценарии

- [ ] В каталоге выберите кошку: видны купание и гигиена, счётчик 2. Верните всех: счётчик 3.
- [ ] У каждой услуги откройте окно «Выбрать»: корректны название, цена и длительность.
- [ ] Закройте окно крестиком и Escape; откройте вновь и перейдите к записи.
- [ ] Через «Подробнее» откройте каждую услугу, проверьте таблицу и ссылку записи.
- [ ] На product раскройте/закройте каждый пункт FAQ.
- [ ] Адрес product.html?service=unknown показывает базовую услугу без ошибок.

## Форма

- [ ] Пустая форма показывает сообщения и переводит фокус на первое ошибочное поле.
- [ ] Неверный e-mail и телефон короче/длиннее 10 цифр не проходят проверку.
- [ ] Имя и кличка из пробелов не проходят проверку.
- [ ] Для кошки стрижка не проходит; купание и гигиена проходят.
- [ ] Вчерашняя дата и дата далее 90 дней не проходят; сегодня предлагается только будущее время.
- [ ] Для 90 минут последнее начало 17:30, для 60 — 18:00, для 30 — 18:30.
- [ ] Без согласия заявка не проходит.
- [ ] Корректные вымышленные данные показывают итог и сообщение, что ничего не отправлено.
- [ ] После изменения данных старый итог скрывается; «Очистить» убирает значения, ошибки и итог.

## Качество и Git

- [ ] На Tab виден фокус, ссылка «Перейти к содержимому» доступна первой.
- [ ] В Console нет ошибок, в Network нет пропавших файлов.
- [ ] После отключения интернета компоненты продолжают работать.
- [ ] README содержит автора, группу, Bootstrap, структуру, доработки и ограничения.
- [ ] GitHub содержит три настоящих объединённых PR и историю коммитов.
- [ ] Итог находится в main; `git status` показывает чистую рабочую папку.
- [ ] Репозиторий открывается преподавателю без приглашения; ссылка подготовлена для СДО.
- [ ] Если используете GitHub Pages, проверена фактическая опубликованная ссылка и добавлена в README.
