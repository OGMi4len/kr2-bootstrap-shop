## Форма

- [ ] Пустая форма показывает ошибки и переводит фокус на первое ошибочное поле.
- [ ] Неверный e-mail, телефон не из десяти цифр, имя/кличка из пробелов отклоняются.
- [ ] Кошка + стрижка или первое знакомство отклоняется; кошка + купание, гигиена, когти или экспресс-линька проходит.
- [ ] Вчера и дата дальше 90 дней отклоняются; воскресенье недоступно; в рабочий день сегодня предлагаются только будущие начала.
- [ ] Начала идут раз в полчаса с 10:00, окончание процедуры не позже 18:00. Для стрижки последнее начало 16:30, купания 17:00, экспресс-линьки 16:30, гигиены/первого знакомства/когтей 17:30.
- [ ] Без согласия заявка не проходит.
- [ ] После «Продолжить» корректные данные показывают «Детали визита готовы», введённые детали и предложение согласовать время с администратором.

- [ ] Изменение данных скрывает старый итог; повторная ошибочная отправка не оставляет прежний успешный результат.
- [ ] «Очистить» убирает значения, ошибки и итог; повторное открытие формы снимает старые ошибки и результат.
